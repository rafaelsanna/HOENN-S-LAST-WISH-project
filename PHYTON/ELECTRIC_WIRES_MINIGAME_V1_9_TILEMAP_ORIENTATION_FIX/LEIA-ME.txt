ELECTRIC WIRES MINIGAME V1.9 - TILEMAP ORIENTATION FIX
=======================================================

A causa real foi identificada:

connectedtoblue.bin e connectedtogreen.bin têm 256 bytes
= 128 entradas de tile.

O desenho correto enviado pelo usuário é:
  8 tiles de largura x 16 tiles de altura
  = 64 x 128 pixels

A V1 interpretava errado como:
  16 x 8
  = 128 x 64 pixels

Isso embaralhava o desenho.

Este patch corrige:
  CONNECT_MAP_W = 8
  CONNECT_MAP_H = 16
  CONNECT_MAP_X = 11
  CONNECT_MAP_Y = 2

Também restaura a regra correta:
ao conectar, os três sprites soltos (rosa, azul e verde) somem.
Fica APENAS o desenho connectedtoblue ou connectedtogreen escolhido.

USO
---
cd ~/pokeemerald-expansion

python3 PHYTON/ELECTRIC_WIRES_MINIGAME_V1_9_TILEMAP_ORIENTATION_FIX/fix_connected_tilemap_orientation.py --dry-run

python3 PHYTON/ELECTRIC_WIRES_MINIGAME_V1_9_TILEMAP_ORIENTATION_FIX/fix_connected_tilemap_orientation.py --compile --jobs 8
