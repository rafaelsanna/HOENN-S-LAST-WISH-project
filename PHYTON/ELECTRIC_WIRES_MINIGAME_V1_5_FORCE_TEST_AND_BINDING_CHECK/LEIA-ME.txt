ELECTRIC WIRES V1.5 - FORCE TEST + BINDING CHECK

Esse script para de adivinhar.

Ele:
1. desfaz o def_special inválido com waitstate=1;
2. troca o Poochyena test script para callnative + waitstate;
3. abre data/maps/LittlerootTown/map.json;
4. confirma se ALGUM object_event realmente usa LittlerootTown_EventScript_Poochyena.

Se nenhum usa, ele PARA e imprime todos os NPCs/objetos com:
index, local_id, graphics_id, posição e script.

Uso:
  cd ~/pokeemerald-expansion
  python3 PHYTON/ELECTRIC_WIRES_MINIGAME_V1_5_FORCE_TEST_AND_BINDING_CHECK/force_test_and_check_binding.py --dry-run

Se disser que binding existe:
  python3 PHYTON/ELECTRIC_WIRES_MINIGAME_V1_5_FORCE_TEST_AND_BINDING_CHECK/force_test_and_check_binding.py --compile --jobs 8
